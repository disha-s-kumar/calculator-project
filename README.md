# Simple Calculator (HTML + CSS + JavaScript)

This is a basic, responsive calculator built using pure HTML, CSS, and JavaScript.  
It supports addition, subtraction, multiplication, division, and clear/delete functions.

##  Features
- Responsive UI
- Neumorphic button design
- Working display screen
- AC (Clear) and DE (Backspace)
- Basic operators + decimal support

## Technologies Used
- HTML
- CSS
- JavaScript (eval based)
